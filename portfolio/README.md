This project is built using [Angular CLI](https://github.com/angular/angular-cli) version 21.1.0 with modern Standalone Components, Angular Signals, and clean modular architecture.

## Development server

To start a local development server:

```bash
npm start
# or: ng serve
```

Navigate to `http://localhost:4200/`. The application will automatically reload if you change any of the source files.

## Build

To compile the application for production:

```bash
npm run build
```

Build artifacts will be generated into the `../docs` directory for GitHub Pages deployment.

## Unit Testing

To execute unit tests using [Vitest](https://vitest.dev/):

```bash
npm test
```

## Code Quality & Formatting

```bash
npm run format:check
npm run format
```
