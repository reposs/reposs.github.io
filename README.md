## 🚀 Sobre el Proyecto

Portafolio profesional desarrollado con arquitectura limpia y modular en **Angular 21**, diseñado para demostrar estándares de ingeniería de software enterprise, reactividad moderna, accesibilidad y rendimiento óptimo.

### 🛠️ Stack Tecnológico

- **Framework**: Angular 21 (Standalone Components, Signals, Zoneless readiness)
- **Lenguaje**: TypeScript 5.9+ (tipado estricto)
- **Estilos**: SCSS modular, BEM, CSS Custom Properties (modo oscuro por defecto sin FOUTh)
- **Internacionalización**: `@ngx-translate/core` (soporte reactivo completo ES / EN)
- **Testing**: Vitest + jsdom
- **Calidad de Código**: Prettier, Clean Code, Arquitectura Modular desacoplada

## 🏛️ Arquitectura del Proyecto

```text
portfolio/src/app/
├── core/                  # Servicios transversales y singleton (i18n, ThemeService)
├── layout/                # Componentes estructurales de maquetación (Header, Footer)
├── shared/                # Componentes y utilidades compartidas reutilizables
└── features/              # Módulos de funcionalidad desacoplados
    ├── cv/                # Modal de CV interactivo, reactividad y preparado para impresión A4
    └── portfolio/         # Páginas y secciones del portfolio (Hero, Metrics, Pillars, Skills, Projects, etc.)
```
